MCP Guard

Secure Gateway & Hardened Execution Layer for Model Context Protocol

01 / 08
The Vulnerability Vector

Standard MCP tools lack authorization barriers, request isolation, and parameter verification. Malicious or compromised agent trajectories can invoke arbitrary execution payloads, leak memory scopes, or execute tool-poisoning attacks unchecked.

Fail-Closed Defense In Depth

Built an audit-first gateway with bearer-key verification hooks, per-key allowlisted tool dispatch, tool-schema fingerprint pinning, rate limiting, and rule-based tool-poisoning detection. Employs isolated Docker runtimes (read-only rootfs, zero network, non-root, strict CPU/RAM/process clamps) and a LangGraph notes agent restricted exclusively through this gateway.

Zero-Trust Isolation: Docker sandbox with read-only root, live SSE audit logs, and fingerprint-pinned tool definitions.

Fire Drill

Chaos Engineering for Human-in-the-Loop AI Oversight

03 / 08
The Automation Blindspot

Human reviewers routinely experience automation complacency, rubber-stamping AI-generated action streams without scrutinizing underlying logic, leading to catastrophic latent failures in production environments.

Canary Injection Pipeline

Designed a Worker–Canary–Auditor topology that injects realistic, benign flaws into AI approval streams. Canary actions are permanently isolated from actual execution. Measured over 62 decisions (50 real + 12 canaries), discovering reviewers caught only 41.7% of canaries.

Empirical Discovery: Human reviewers caught 5/12 canaries (41.7%), demonstrating severe reviewer fatigue under volume.
